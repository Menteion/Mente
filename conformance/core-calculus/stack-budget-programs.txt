# The programs of the reviews of pull request 136, the stack budget, and their frames
#
# Each program the fourteen reviews of `core-calculus.md` item 25 used, with what it waits on.
# `waits: none` marks a program the checker runs today: its source follows `---`, and
# `frames:` states the frame item 25 gives each function named, which the test
# `test_review_programs_give_the_frames_they_state` in `compiler/mente-sema/tests/frames.rs`
# holds the checker to. Every figure here is derived from item 25's equations by hand, or by
# the reviews' scripts written before the checker counted, never by the checker, which this
# list judges (Norman's decision `executable-rule-models`, 2026-11-15); a new entry's frames
# are derived the same way. A program that waits names the construct it needs (`?T`,
# `T ! E`, views, `List<T>`, `String`, `own`); the pull request that brings the construct
# gives it its source and its frames. `refused` marks a program the reviews settled as an
# error, which has no frame; the constructs after it are what it needs to be refused, and the
# pull request that brings them makes it a conformance program that fails. No two entries
# hold the same program. `outcome` and `was` are the reviews' readings: in rounds 1 to 10,
# figures of the count as it stood before the amendment of 2026-11-15 (A').
