## What the compiler does not do yet

These gaps hold across every crate, and every `spec/*.md` claim that depends on them is labelled `Specified`:

- **Bodies are checked for M1's slice only.** The body parser reads every function with a body under M1's grammar, and name resolution and the type checker check M1's names, types and parameter modes in each function that parses cleanly. `@example` bodies stay token lists, and the declaration parser keeps the types, contracts and effect clauses of declarations as raw strings for the digests.
- **Proofs for M1's slice only, and no checks beyond its types.** Tier 1 proves M1's refinements, contracts and `decreases` measures, mutual recursion aside; Tier 2 (`mn prove`) does not exist, so a `@prove` clause is a trusted axiom; units, `?T`, `T ! E`, effects and the Law of Exclusivity beyond a single call are not checked.
- **Lowering and native code for M1's slice only.** Functions of M1's calculus lower to MIR and compile through Cranelift; MIR has no optimisation beyond leaving out the checks Tier 1 proves, and native code no target but x86-64 and AArch64 Linux and x86-64 Windows.
