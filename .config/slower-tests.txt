# The tests whose time a change accepts, one a line as
# `<kind> <runner> <binary id> <test name> <value>  # why`, the test as nextest prints it and the
# runner by the label its Rust job runs on (.github/scripts/lib/test-times.mjs judges them):
# - `slower <runner> ... <factor>`: on a Linux runner, the factor over main's baseline, at the run's
#   speed, the test may take, more than the 1.5 every test may; for a change that means to make a
#   test slower. Name the change.
# - `near-limit <runner> ... <share>`: the share of the test's stop, past the 60% every test may
#   take and under 1, it may take on that runner. Name the fix scheduled for it.
# A line the run no longer needs, the factor within 1.5 or the test under half the headroom, or one
# that names a test the run lacks, fails a pull request and the queue: remove it then. CODEOWNERS
# gives the file to its owner, so review sees every line.
